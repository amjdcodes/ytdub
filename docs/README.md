# أداة CLI لتحميل فيديوهات يوتيوب مع الدبلجة — ملف البحث الاحترافي

> **الحالة:** بحث تقني مكتمل — ليس كودًا بعد.
> **الهدف:** أداة سطر أوامر بلغة Python تطلب رابط فيديو يوتيوب من المستخدم، تعرض الجودات والدبلجات المتوفرة بشكل مرتب، ثم تُحمّل الفيديو بالدبلجة والجودة التي يختارها المستخدم.
> **اللغة:** العربية للشرح + الإنجليزية للمصطلحات التقنية والأوامر.

## لماذا هذه الوثائق احترافية وليست عادية؟

1. مبنية على **المصادر الرسمية فقط**: مستودع `yt-dlp` (README + Wiki + الكود المصدري للمستخرج)، توثيق `FFmpeg` الرسمي، توثيق `Rich`.
2. تشرح **لماذا** كل مكتبة مختارة و**ماذا تستبعد** (مثل `pytube`).
3. تعطيك **الصيغ الجاهزة** لاختيار الفورمات (`-f`, `-S`) و**أوامر الدمج** دون تخمين.
4. تنتهي بمخطط معماري + خارطة طريق تنفيذ مباشرة.

## الخلاصة التنفيذية (اقرأ هذا أولًا)

```
المستخدم يدخل URL
      ↓
yt-dlp (مكتبة Python) يستخرج info_dict بدون تحميل
      ↓
نعرض جدولين بـ Rich:
  1) الدبلجات: من audioTrack.id + language + audioIsDefault
  2) الجودات: من formats (height/res/fps/vcodec + filesize)
      ↓
نبني format string دقيق: bv*[height<=X]+ba[language=Y] / b[language=Y]
      ↓
yt-dlp يحمّل + ffmpeg يدمج (merge) إلى mp4/mkv
```

**المكدّس النهائي الموصى به:**

| الدور | الاختيار | البدائل المستبعدة ولماذا |
|-------|----------|---------------------------|
| استخراج وتحميل | `yt-dlp` (مكتبة Python) | `pytube`/`youtube-dl` — متوقفة أو تفشل مع مسارات الصوت المتعددة وPO Token |
| دمج ومعالجة | `ffmpeg` + `ffprobe` (ثنائي خارجي) | لا تستخدم حزمة `ffmpeg` على PyPI — المطلوب الثنائي الحقيقي |
| واجهة CLI | `rich` للجداول والتقدم + `click` أو `rich-click` للأوامر + `questionary` للاختيار التفاعلي | `argparse` وحده — فقير بصريًا ولا يكفي لعرض مرتب |
| JS Challenge | `deno` (موصى به) أو `node` + حزمة `yt-dlp-ejs` | بدونها يفشل دعم يوتيوب الكامل |

## القرارات الحاسمة التي توصّل إليها البحث

1. **لا تعتمد على progressive formats** (فيديو+صوت في ملف واحد، غالبًا ≤720p). الجودات العالية في يوتيوب **دائمًا منفصلة** (DASH) وتحتاج دمجًا.
2. **الدبلجة = مسار صوتي (audio track) منفصل** له `language` و`audioTrack.displayName`. ليست ترجمة (subtitle). تُختار عبر `ba[language=xx]` أو `format_id` مباشرة.
3. **الحاوية الافتراضية يجب أن تكون `mkv` عند تعدد المسارات**، و`mp4` عند مسار واحد (لتوافق المشغلات). `mp4` لا يحمل Opus بكفاءة في النسخ القديمة.
4. **Python المطلوب ≥3.10** (CPython) حسب توثيق `yt-dlp` الرسمي.
